Reps Weekly Operations Dashboard Privacy Policy

Last updated: 11 September 2026

The Reps Weekly Operations Dashboard is a private administrative tool used by the developer of Reps Weekly. It is not intended for general public account access.

Google API Data

The dashboard uses Google OAuth and Google APIs under the developer's own Google account to retrieve operational information required to administer Reps Weekly.

Google data accessed may include:

  • Gmail metadata required to count unread Reps Weekly helpdesk messages.
  • Google Analytics and Firebase Analytics reporting data used to display aggregate app usage statistics.
  • Google AdMob reporting data used to display aggregate advertising revenue.

The dashboard may also retrieve aggregate operational counts from Firebase and Firestore, including deletion requests, bug reports and player reports.

How Data Is Used

Google user data is used only to operate and administer Reps Weekly and the Reps Weekly Operations Dashboard.

Google user data obtained through Google APIs is not sold and is not used for advertising targeting.

Google user data obtained through Google APIs is not transferred to third parties except where necessary to provide the underlying services or where required by law.

Access is limited to the developer's own authorised Google account.

Data Storage

The dashboard stores aggregate metric values in a private Google Sheet for operational display and administration.

The public browser-facing dashboard receives aggregate metrics only. It does not expose OAuth access tokens, Google account credentials, or the contents of Gmail messages.

The browser dashboard may cache the latest aggregate dashboard response locally in the browser to support temporary connection failures and offline fallback.

Google API Services User Data Policy

Use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

For questions regarding this Privacy Policy, contact: repsweekly.com
